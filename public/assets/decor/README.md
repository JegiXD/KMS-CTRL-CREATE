# Dekorativni glasbeni motivi

Izvirne linijske SVG ilustracije, ki jih je Codex napisal za uporabnikovo zahtevo 4. 11. 2026:

- `guitar.svg` — akustična kitara; 360 × 520, 1.404 B.
- `accordion.svg` — harmonika; 500 × 360, 1.864 B.
- `stage.svg` — bobni, mikrofon in kitara; 560 × 400, 1.341 B.

Skupaj 4.609 B pred stiskanjem. Izvor so lokalne SVG poti v tej mapi, brez zunanjih slik, ikon ali prevzetih ilustracij. To niso fotografije KMŠ, predstavitve konkretnega benda ali uradni simboli znamke. Ni prevzetih dovoljenj tretjih oseb; ločena licenca projekta ni določena.

CSS ozadja so dekorativna, brez semantične vsebine, zato nimajo alt opisa in ne vstopajo v dostopnostno drevo. Uporabljajo rdečo `#E32636` pri 12 % opacity, na telefonu 7,5 %. Nimajo animacij, zunanjih referenc ali filtrov in ne sprejemajo klikov. Popis in predogledi so v `docs/ASSETS_AND_SOURCES.md` in `docs/BRAND_COLORS.md`. Rastrski popis `ASSET_INVENTORY.json` teh vektorskih datotek ne vključuje.

`facet-pattern.svg`: izvirna ponovljiva geometrija za rdeča ozadja #D92333, napisana s Codexom po uporabnikovi referenci. Referenčna slika ni vključena ali kopirana. Trenutne linije #7A0C18, 32 % opacity, debelina 1,6. Uporabnikovo/Copilot različico je Codex pri pregledu umiril; dekorativno, brez zunanjih virov ali animacije.
