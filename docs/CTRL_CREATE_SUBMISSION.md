# CTRL+CREATE 2026 — predstavitev projekta

## Naslov projekta

**KMŠ Editorial – Interaktivna spletna podoba Kluba mariborskih študentov**

## Ideja projekta

Spletna podoba Kluba mariborskih študentov je zasnovana kot interaktivna digitalna revija o mladih, glasbi in skupnosti v Mariboru. Izhodišče je vprašanje, kako obiskovalcu hitro in privlačno predstaviti, kaj KMŠ počne in kako se lahko vključi. Namesto dolgega seznama informacij ga spletna stran vodi od uvodne predstavitve skozi ljudi, projekte in novice do članstva ter konkretnih možnosti sodelovanja.

Eksperimentalni uredniški koncept uporablja veliko tipografijo, asimetrične fotografske postavitve, izvirne ročne SVG-poteze in prepoznavno rdečo identiteto KMŠ na toplih svetlih podlagah. Fotografije resničnih projektov povezujejo glasbo, ustvarjanje, druženje in dobrodelnost; njihovi viri so navedeni v projektu. Scroll zgodba po Bézierjevi poti spremeni drsenje v del pripovedi: fotografije se premikajo iz leve proti desni in nazaj, sekcije pa se vizualno nadaljujejo druga v drugo.

Navigacija ohranja ločene poti do predstavitve kluba in organov, projektov, arhivskih novic, članstva, priložnosti, kontakta in e-novic. Filtri pomagajo pri odkrivanju projektov, članstvo vodi na uradni obrazec, kontakt pa pripravi e-poštni osnutek. E-novice so jasno označene kot neaktivna demonstracija. Odzivna postavitev prilagodi fotografsko zgodbo različnim zaslonom, nastavitev zmanjšanega gibanja pa zamenja animacije s statično postavitvijo. Cilj je sodobna predstavitev, ki pokaže KMŠ kot prostor, kjer mladi ideje spremenijo v skupna doživetja.

## Uporabljena orodja

- **Razvoj:** React, TypeScript, Vite, React Router, CSS.
- **Animacije:** GSAP, ScrollTrigger, MotionPathPlugin in Lenis.
- **Ikone:** Lucide React.
- **AI-podpora:** ChatGPT in OpenAI Codex sta dokumentirana v projektnih zapiskih; GitHub Copilot je naveden v zgodovini in kot soavtor v metapodatkih dveh commitov. Natančen obseg je razčlenjen v [AUTHORSHIP.md](AUTHORSHIP.md).
- **Različice kode:** Git in zasebni GitHub repozitorij.
